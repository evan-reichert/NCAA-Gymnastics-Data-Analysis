# NCAA Gymnastics Performance Analytics

A Python-based data analytics project evaluating multi-year NCAA gymnastics performance data to quantify team dominance, improvement trends, and event-level predictive strength.

---

## Overview

This project analyzes historical NCAA gymnastics competition data using Pandas and Matplotlib to:

- Rank team performance across multiple seasons
- Measure consistency and improvement trends
- Identify which events are most predictive of total team score
- Generate visual performance comparisons

The goal was to move beyond raw rankings and develop custom performance metrics using statistical and grouped data analysis.

---

## Key Features

### Custom Performance Metrics
- Built dominance metrics using grouped aggregations
- Developed improvement scoring based on year-over-year change
- Calculated consistency indicators using variance and distribution analysis

### Advanced Data Aggregation
- Applied multi-level `groupby()` operations
- Performed correlation analysis between event scores and total score
- Aggregated championship wins and top-4 finishes

### Visualization
- Generated ranked performance charts using Matplotlib
- Visualized event impact on total score
- Produced comparative team performance graphs
